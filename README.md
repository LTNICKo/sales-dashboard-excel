# 📊 Sales Dashboard Project (Excel)

## 📌 Project Overview
This project is an interactive sales dashboard built in Excel to analyze business performance across regions, products, and sales teams.

## 🎯 Objectives
- Track total revenue and profit
- Analyze regional performance
- Identify top-performing products
- Evaluate sales team performance

## 📂 Dataset
The dataset contains:
- Date
- Region
- Product Category
- Salesperson
- Units Sold
- Revenue
- Profit

## 📊 Dashboard Features
- KPI Cards (Revenue, Profit, Units Sold)
- Dynamic filters (Region, Product, Month)
- Sales trends over time
- Top 5 products analysis
- Salesperson performance breakdown

## 🔍 Key Insights
- The highest revenue came from North
- Electronics generated the most profit
- Sales peaked during March

## 💡 Recommendations
- Focus on high-performing regions
- Increase inventory for top products
- Support underperforming sales teams
